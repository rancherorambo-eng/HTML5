Ejemplo de tipos de medios CSS

Este ejemplo utiliza tipos de medios CSS para variar cómo se muestra la página al imprimirse y cómo aparece en cualquier otro medio. Este texto aparecerá con una fuente en la pantalla y con una fuente diferente en papel o en una vista previa de impresión. Para ver la diferencia en Internet Explorer, ve al menú Imprimir y selecciona Vista previa de impresión. En Firefox, selecciona Vista previa de impresión desde el menú Archivo.
