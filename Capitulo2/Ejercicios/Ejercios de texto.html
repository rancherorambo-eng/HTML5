Ejercicio 2.10: Identificación de Elementos y Atributos

  • a) html: Elemento (es el contenedor raíz que engloba toda la página Web).
  • b) width: Atributo (se utiliza para fijar la anchura de recursos como imágenes o celdas).
  • c) href: Atributo (indica la ruta o URL de destino en un hipervínculo).
  • d) br: Elemento (genera un salto de línea y no requiere etiqueta de cierre).
  • e) h3: Elemento (define un título o encabezado de tercer nivel en la jerarquía).
  • f) a: Elemento (la etiqueta ancla, indispensable para construir enlaces interactivos).
  • g) src: Atributo (establece la fuente o ruta de origen para cargar contenido multimedia).

Ejercicio 2.11: Análisis de Afirmaciones (Verdadero / Falso)

  1. Falso. La especificación de HTML5 es flexible y permite procesar etiquetas en mayúsculas. Sin embargo, el estándar de la industria es escribirlas siempre en minúsculas por legibilidad.
  2. Verdadero. Es perfectamente válido guardar los archivos web usando indistintamente la extensión .htm o .html.
  3. Falso. Para renderizar el símbolo "menor que" (<), la entidad correcta es &lt;. La sintaxis &less; no es reconocida por el navegador.
  4. Verdadero. Las etiquetas de ítem (<li>) forzosamente deben ir agrupadas dentro de contenedores de listas ordenadas (<ol>) o desordenadas (<ul>).

Ejercicio 2.12: Completar los Conceptos

  1. Para insertar notas o comentarios en el código, el bloque debe abrir con <!-- y finalizar con -->.
  2. Los valores que se le asignan a los atributos pueden delimitarse utilizando comillas dobles (" ") o comillas simples (' ').
  3. El código especial (entidad de carácter) para mostrar el símbolo de ampersand (&) es &amp;.
  4. Para destacar un texto dándole un formato de negrita, la etiqueta semántica recomendada es <strong> (o la clásica <b>).

Ejercicio 2.13: Clasificación Adicional

  • a) width: Atributo (controla la expansión horizontal de un elemento).
  • b) td: Elemento (define una celda de datos estándar dentro de una fila de tabla).
  • c) th: Elemento (define una celda de encabezado para titular columnas o filas).
  • d) name: Atributo (se usa para asignar un identificador a controles y variables de formulario).
  • e) select: Elemento (permite construir menús o listas desplegables).
  • f) type: Atributo (determina el comportamiento, validación y apariencia de un campo de entrada <input>).
