Ejercicio 3.4: Verdadero o Falso

  1. Falso. Si un navegador no soporta la interfaz gráfica de selección de color para input type="color", el usuario introduce un código de color hexadecimal (ej. #FF0000), no el nombre del color.
  2. Verdadero. El navegador verifica automáticamente que los datos cumplan con las restricciones definidas en el formulario antes de enviarlo.
  3. Falso. HTML5 únicamente verifica la sintaxis del correo electrónico (que tenga formato usuario@dominio.com), pero no valida si la cuenta existe en la realidad.
  4. Verdadero. El atributo required puede agregarse a casi cualquier tipo de entrada para marcarlo como obligatorio.
  5. Verdadero. El atributo autocomplete se puede habilitar o deshabilitar para elementos input individuales.
  6. Verdadero. El elemento time permite especificar una fecha, una hora o ambas de forma estructurada.
  7. Falso. La leyenda para una imagen dentro de figure es figcaption. El elemento caption se utiliza únicamente para el título de las tablas.
  8. Verdadero. El elemento details muestra/oculta contenido interactivo guiado por la etiqueta summary.
  9. Verdadero. El elemento footer representa el pie de página de un documento o sección.
  10. Falso. Para resaltar texto se utiliza el elemento <mark>; la etiqueta highlight no existe en el estándar HTML5.
