Ejercicio 3.3: Complete las siguientes oraciones

  1. El atributo autofocus (que se utiliza en un solo elemento input en un formulario) resalta de manera automática el elemento input y coloca el cursor en el campo de texto.
  2. Los nuevos tipos input de HTML5 tienen validación del lado del cliente.
  3. El tipo input number permite al usuario introducir un valor numérico.
  4. El tipo input range se valida automáticamente de manera intrínseca cuando lo despliega el navegador como un control deslizante.
  5. El atributo autocomplete puede usarse en los tipos input para completar de manera automática la información del usuario con base en datos anteriores.
  6. El elemento figcaption proporciona una leyenda para la imagen en el elemento figure.
  7. El elemento summary muestra una flecha... Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento details.
  8. El elemento mark nos permite resaltar texto.
