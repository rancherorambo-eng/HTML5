Ejercicio 10.13: Orden de elementos en el arreglo ventas (3x5)

Segmento de programa analizado[cite: 3]:

for ( var fila in ventas )
{
    for ( var col in ventas[ fila ] )
    {
        ventas[ fila ][ col ] = 0;
    }
}

Orden en el que se establecen en cero:

Debido a los ciclos anidados for...in, el ciclo externo recorre cada una de las filas (0, 1 y 2) y el ciclo interno recorre cada una de las columnas (0 a 4) secuencialmente:

  1. ventas[0][0]
  2. ventas[0][1]
  3. ventas[0][2]
  4. ventas[0][3]
  5. ventas[0][4]
  6. ventas[1][0]
  7. ventas[1][1]
  8. ventas[1][2]
  9. ventas[1][3]
  10. ventas[1][4]
  11. ventas[2][0]
  12. ventas[2][1]
  13. ventas[2][2]
  14. ventas[2][3]
  15. ventas[2][4]
