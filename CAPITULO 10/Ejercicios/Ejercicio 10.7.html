Ejercicio 10.7: Verdadero o Falso

  1. Falso. Para hacer referencia a un elemento específico en un arreglo, especificamos el nombre del arreglo y el número de índice (o posición) del elemento, no su valor.
  2. Falso. La declaración de una variable (como let x;) solo reserva espacio para esa variable escalar. Para reservar espacio para un arreglo se debe instanciar explícitamente (por ejemplo, let p = new Array(100); o usando un literal de arreglo let p = [];).
  3. Falso. En JavaScript la sintaxis p[100]; no declara un arreglo de 100 elementos; se debe usar let p = new Array(100); o asignar valores dinámicamente.
  4. Falso. Se pueden inicializar los elementos de un arreglo sin usar un bucle for, por ejemplo mediante el método fill() (let arr = new Array(15).fill(0);) o usando literales de arreglo (let arr = [0,0,0,...];).
  5. Falso. Aunque tradicionalmente se usan dos ciclos for anidados para iterar matrices, también es posible calcular el total utilizando métodos de arreglo modernos como flat() y reduce() (por ejemplo, matriz.flat().reduce((a, b) => a + b, 0)).
